Requirements

  • LibreOffice 7.0+
  • Ollama installed and a model pulled, e.g.: 
    ollama pull llama3.1
    Confirm it's serving: curl http://localhost:11434/api/tags
  • On Linux, the LibreOffice Python script provider must be installed (usually a separate package from the base LibreOffice install): 
    sudo apt install libreoffice-script-provider-python
    Windows and macOS bundle this with LibreOffice already.

Setting up Ollama

If you don't have Ollama running yet, here's the full setup from scratch — pick your OS below. All three end up with the same thing: a local Ollama service listening on http://localhost:11434.

Windows

Step 1: Download and install Ollama

  1. Go to the official Ollama website: ollama.com/download.
  2. Click Download for Windows to download OllamaSetup.exe.
  3. Run OllamaSetup.exe and click Install.
  4. Once installation completes, Ollama runs automatically in the background. You'll see a small Ollama icon in the Windows system tray (bottom-right corner, near the clock).

Step 2: Open a terminal

  1. Press Windows key + R, type cmd (or powershell), and press Enter.
  2. Verify Ollama is installed: 
    ollama --version
    You should see a response like ollama version is 0.x.x.

Step 3: Pull and run a model

In the same terminal, download and launch a model, e.g. gemma2:2b:

ollama run gemma2:2b
  • Ollama will download the model weights (gemma2:2b is about 1.6 GB).
  • Once downloaded, you'll see a >>> prompt, meaning the model is loaded and ready to chat.

Step 4: Verify the local API

Ollama automatically exposes a local HTTP API on port 11434 as soon as it's running — no extra setup needed. Open a browser and go to http://localhost:11434/. If you see “Ollama is running”, the endpoint is live and ready to accept requests from the extension.

macOS

Step 1: Download and install Ollama

  • Direct download: visit ollama.com/download and download Ollama-darwin.zip. Unzip it and drag the Ollama app into your Applications folder.
  • Via Homebrew (alternative): open Terminal and run: 
    brew install ollama

Step 2: Launch Ollama

  1. Open Ollama from your Applications folder (or Launchpad).
  2. A small llama icon appears in the top macOS menu bar, confirming the background service is running.
  3. If prompted to install command-line tools, click Install and enter your Mac password.

Step 3: Pull and run a model

Open the Terminal app (Cmd+Space, type Terminal, press Enter), then:

ollama run gemma2:2b

After downloading (~1.6 GB), a >>> prompt appears when it's ready.

Step 4: Verify the local API

Open Safari or Chrome and navigate to http://localhost:11434/. Seeing “Ollama is running” confirms the local HTTP endpoint is ready for plugin calls.

Linux (Ubuntu, Debian, Fedora, Arch)

Step 1: Run the install script

Open your terminal application and run the official Ollama install script:

curl -fsSL https://ollama.com/install.sh | sh

This automatically downloads the binary, sets up system permissions, and configures Ollama as a background systemd service.

Step 2: Verify the service

Check that the service is active and running in the background:

sudo systemctl status ollama

If it's active, query its version to confirm the CLI path is configured:

ollama -v

Step 3: Pull and run a model

ollama run gemma2:2b

Once the weights download, test the interactive shell. Type /bye to exit when done testing.

Step 4: Verify the local API

Test the server locally from the terminal:

curl http://localhost:11434

If it returns “Ollama is running”, local integrations like RedactAI can communicate with the service.

Useful Ollama commands

  • Exit interactive chat: type /bye or press Ctrl+D.
  • List downloaded models: ollama list.
  • Pre-download a model without starting chat: ollama pull gemma2:2b.

Install

First, download redactai.oxt from the Releases page. Then use either method below.

Method 1: Double-click install (easiest)

  1. Make sure LibreOffice is installed on your computer.
  2. Locate the downloaded redactai.oxt file in your file explorer.
  3. Double-click the .oxt file — LibreOffice launches and automatically opens the Extension Manager.
  4. Choose Only for me or For all users if prompted.
  5. Click Accept if a license agreement appears, then restart LibreOffice.

Method 2: Via Extension Manager

  1. Open LibreOffice (or open Writer directly).
  2. From the top menu, go to Tools > Extension Manager… (or press Ctrl+Alt+E).
  3. In the Extension Manager window, click Add….
  4. Browse to your downloaded redactai.oxt file, select it, and click Open.
  5. Choose Only for me or For all users if prompted.
  6. Close the Extension Manager window and restart LibreOffice — extensions are only picked up on startup.

To uninstall: remove it via Tools > Extension Manager.

First run

Open Tools > RedactAI > Settings and set the model name to whatever you've pulled (defaults to llama3.1). If Ollama runs on another machine or a non-default port, update the endpoint here too. The sidebar panel reads the same settings file, so there's nothing separate to configure there.

Usage

There are two ways to use RedactAI:

Sidebar panel (View > Sidebar)

Quick rewrite actions, a custom instruction, and Brainstorm, all working from your current selection — with a review step before anything touches the document.

FeatureWhat it does
OriginalRead-only preview that auto-updates as you select text in Writer.
Quick actionsImprove / Fix grammar / Shorten / Make formal / Summarize, applied to the current selection.
CustomFree-text rewrite instruction, applied the same way a quick action would be.
Brainstorm on Selection5 bullet ideas using the selection as topic.
Suggested rewriteEditable. Nothing is written to the document until you choose Replace Selection, Insert Below, Copy, or Discard.

Tools > RedactAI menu

The original popup-dialog versions (Generate / Brainstorm / Rewrite) — these auto-insert directly with no review step — plus Settings. Kept as a fallback alongside the sidebar panel.

Troubleshooting

“Ollama didn't respond within Ns” — default timeout is 180s. The first request after Ollama's been idle can take longer than that just to load the model into memory. Raise the timeout in Settings if this happens regularly. ollama ps shows whether a model is currently loaded.

  • Clicking Fetch in Settings closes and reopens the dialog to refresh the model list — other field edits carry over, but it'll flash shut and reopen rather than updating in place.
  • No streaming — you wait for the full response before it's inserted.
  • If the sidebar panel doesn't show up at all, try running LibreOffice from a terminal (soffice --writer) so any Python error prints there.
