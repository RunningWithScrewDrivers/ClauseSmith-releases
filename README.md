# ClauseSmith

Public home for [ClauseSmith](https://github.com/RunningWithScrewDrivers/ClauseSmith)
downloads and documentation. ClauseSmith is a LibreOffice Writer extension
that talks to a local Ollama server for drafting, brainstorming, and
rewriting text.

- **Download the extension:** see the [Releases](../../releases) page for
  the latest `clausesmith.oxt`.
- **Help / docs:** [docs/](docs/) (published via GitHub Pages).
- **Source code:** kept in a private repository; this repo only receives
  built releases and documentation, published automatically from there.

To install: LibreOffice > Tools > Extension Manager > Add > select the
downloaded `clausesmith.oxt`, then restart LibreOffice.
